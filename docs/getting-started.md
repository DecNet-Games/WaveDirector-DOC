# Getting Started

Three ideas explain the whole system.

## 1. Pacing is designed as a curve, not tuned per wave

You define how difficulty rises over a run — one curve, with segments, plateaus and spikes. The engine evaluates that curve to a difficulty value for any wave or moment. When pacing feels wrong, you change the curve's shape, not forty table rows.

## 2. Difficulty becomes enemies through a budget

Each wave's difficulty value becomes a spawn budget. Enemies cost points. The director composes the most wave it can honestly buy under your composition rules — so a wave is a costed decision, never "whatever the table said." Composition is deterministic: same curve, wave and seed, same wave.

## 3. Playtests produce evidence

Every directed run records telemetry per wave. The pacing graph plots the difficulty you designed against what actually happened — where players cruised, where they nearly died. Tuning stops being vibes.
